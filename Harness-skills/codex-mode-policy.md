## 用户偏好：每轮运行模式

在每个新的用户请求轮次开始，若该轮尚未明确指定模式，主动简短询问：“本轮仅用 Codex，还是使用 Harness（按当前 API 分工并独立复审）？”用可用的交互提问工具；没有该工具则直接询问。用户回答此选择属于当前轮的延续，不再重复询问。工具轮询、进度更新、压缩恢复、子agent消息不是新用户请求，不因此重复询问。明确说“仅Codex”或“Harness”时直接采用，不重复确认。

等待选择时仅做本地准备或必要只读检查，不调用额外模型API、不进入付费多模型步骤。用户选仅Codex时，可用正常检索/文件/代码/任务所需连接器，但不调用第三方模型；如需要独立审查，可用另一Codex agent并如实标记“同模型家族独立会话”，不能冒充跨模型审查。Harness模式使用已安装的 $harness-skills，核对当前项目API、授权与路由；选择模式不自动授权购买、上传未授权敏感数据或修改凭证。

模式选择默认仅对当前请求有效。用户可明确改为整项任务或持续默认，遵从最新选择。该偏好来自用户，不是要求任何项目必须付费或必须调用外部模型。不要将选择写入待发布的项目秘密信息。

## 用户偏好：额度递补

额度不足时不使用重置卡、不自动购买。用户已要求使用Kimi或其它已授权API继续；切换前核对相关项目范围、端点及数据授权，不把其它对话中的密钥复制进技能或仓库，不绕过平台审批。若用户之后明确禁止外部模型，以最新选择为准。
