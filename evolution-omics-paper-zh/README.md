# evolution-omics-paper-zh

新基因、从头起源、进化基因组学、调控创新和相关组学论文的中文精读加强版。

## 适用场景

- 需要评估新基因或 de novo 起源证据；
- 需要检查系统发育、同源性、保守性和功能证据层级；
- 论文包含进化基因组学或组学测量，需要在通用精读之外增加领域核查。

## 交付内容

默认交付两个独立 Word：

1. 中文全文译本；
2. 独立精读报告。

报告在通用结构基础上增加起源、同源、功能层级和组学证据评价。中英逐段对照、局部翻译和其它格式按用户要求启用。

## 执行入口

使用前按顺序阅读：

- [SKILL.md](SKILL.md)：主流程和边界；
- references/workflow.md：来源、范围和图表映射；
- references/domain.md：进化领域加强规范；
- references/word-output.md：Word 输出规范；
- references/search-evidence.md：检索和证据记录；
- references/omics-review.md：组学测量分支；
- references/reading-design.md：双文件阅读设计。

领域结论仍须由原文定位或外部可核查来源支持。

## 边界

本 skill 不自带全文获取权限、模型服务或 Word 渲染引擎。无法核实的起源、同源、功能或组学结论必须标出证据缺口；不伪造 DOI、实验结果、系统发育关系或验证通过。它不替代原始数据分析，也不会自动上传论文或发布到 GitHub。
