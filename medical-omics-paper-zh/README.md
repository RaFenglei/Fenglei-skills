# medical-omics-paper-zh

医学、生物医学、临床和组学论文的中文精读加强版，重点审查研究设计、偏倚、临床效应和组学验证。

## 适用场景

- 需要评价临床研究设计、患者独立性、混杂和偏倚；
- 需要区分统计关联、机制证据和转化证据；
- 论文包含医学组学测量，需要把测量类型、验证链和临床解释纳入精读。

## 交付内容

默认交付两个独立 Word：

1. 中文全文译本；
2. 独立精读报告。

报告在通用结构基础上增加研究设计、患者/样本独立性、偏倚、临床效应、组学验证和转化证据评价。它不提供个体诊断或治疗建议。

## 执行入口

使用前按顺序阅读：

- [SKILL.md](SKILL.md)：主流程和边界；
- references/workflow.md：来源、范围和图表映射；
- references/domain.md：医学领域加强规范；
- references/word-output.md：Word 输出规范；
- references/search-evidence.md：检索和证据记录；
- references/omics-review.md：组学测量分支；
- references/reading-design.md：双文件阅读设计。

医学结论、临床意义和组学解释都必须绑定原文或可核查来源，不能把模型意见写成作者结果。

## 边界

本 skill 不自带全文获取权限、模型服务或 Word 渲染引擎。无法核实的样本信息、临床终点、效应量、验证结果或视觉检查必须如实记录；不伪造 DOI、实验结果或临床建议，也不自动上传论文或发布到 GitHub。
