# 技术路线图

目的：让读者看懂作者如何从研究问题，经实验/数据和方法，得到关键证据及结论。先读取相关Results、Methods和关键图注，列真实步骤及对应小节，再绘图。

建议结构：研究问题 → 样本或数据来源 → 关键实验/预处理 → 主要分析 → 验证与对照 → 发现和适用范围。按论文实际流程分支汇合，不强行六步，临床/理论/定性研究用其真实研究设计。

对每个节点说明输入、操作或输出中的必要信息；数据流箭头用实线，外部验证/可选分支用明确文字或不同线型。训练与测试分开，实测与计算推断分开，关联与因果证据分开。未做的后续建议不能放进作者技术路线，可另画标明“建议”的图。

用标准矢量/绘图库生成示意图，中文字体、适量留白、图内文字在Word实际插入尺寸下可读。SVG可作编辑源，PNG或兼容矢量图嵌入DOCX；图中文字不能只在外链中。不得用生成式工具重绘原始科研数据图。新作技术路线图不是原图替代品，也不能附上虚构数据。

图注给出图号、所示流程、章节来源和图形身份。报告正文逐步解读图；绘制后对照正文核实节点、方向、数值和验证范围，并实际渲染Word检查。无法可靠绘图时保留已核实的文字路线并明确图未完成，不能以纯文本箭头假称已配图。
